How to redact a volume in Acrobat

  1. Open a volume. Start with {{ first_volume }}. The index on its first pages lists every message{% if bates %}, its page numbers,{% endif %} and whether it contains pictures. {%- if appendix_volumes %} The attachment volumes can wait until the message volumes are done.{% endif %}
  2. Mark the names. In All tools choose Redact, then Redact text & images, then Find text. Pick Multiple words or phrases, click Select words, then Import, and choose {{ wordlist_name }} from this folder. Remove the people this request is about and any department or shared-mailbox names, then Search, Check all, and Mark checked results for redaction. Choose “All PDF documents in” this folder to cover every volume in one pass.
  3. Page through. Read every page and mark what the word list cannot find: names inside the text of a message, in a picture, or in an attachment. The index’s Pict. column shows which messages contain pictures. Drag a rectangle over words inside a picture with Redact text & images.
  4. Apply and save. Click Apply, leave “Sanitize and remove hidden information” ticked, and save the copy Acrobat proposes. Do this for each volume. If you want one file per message, split at bookmarks before applying, because sanitizing removes bookmarks. Send only the sanitized copies.
